1. kesinambungan PWD–DPW–DPWL;
    
    jawaban:  
PWD sudah dipelajari pada semester 1 sebagai dasar dalam membuat dan memahami pemrograman web. DPW dipelajari pada semester 2 sebagai lanjutan dari PWD, salah satunya dengan membuat web yang berhubungan dengan data rumah sakit. DPWL dipelajari pada semester 3 untuk melanjutkan dan mengembangkan pembelajaran sebelumnya, salah satunya dengan menggunakan konsep MVC.


2. perbedaan PHP terstruktur dan MVC;
    
    jawaban:

    *PHP terstruktur* biasanya menempatkan proses program dan tampilan dalam kode yang masih sederhana dan dapat bercampur. Sedangkan *MVC* membagi program menjadi tiga bagian, yaitu Model, View, dan Controller sehingga kode lebih teratur dan mudah dikembangkan.

3. fungsi Model, View, dan Controller;

    jawaban:

    Model berfungsi untuk mengatur data dan bagian yang berhubungan dengan database. View berfungsi untuk mengatur tampilan yang akan dilihat oleh pengguna. Sedangkan Controller berfungsi untuk mengatur proses dan menjadi penghubung antara Model dan View.


4. alur request–response MVC;

    jawaban:

    User melakukan request, kemudian Controller memprosesnya. Jika membutuhkan data, Controller meminta Model untuk mengolah data. Setelah itu hasilnya diberikan ke View untuk ditampilkan kepada User sebagai response.

5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan; 

    jawaban:

    saya membuat aplikasi web yang berhubungan dengan data rumah sakit. Jika aplikasi tersebut menggunakan konsep MVC, bagian data pasien dapat dimasukkan ke dalam Model karena berhubungan dengan data dan database. Kemudian proses untuk menambah, menampilkan, mengubah, dan menghapus data pasien dapat dilakukan oleh Controller. Sedangkan halaman atau tampilan data pasien yang dilihat oleh pengguna termasuk ke dalam View.
